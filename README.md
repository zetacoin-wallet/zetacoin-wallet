This is the GitHub home of Zetacoin Wallet, the open-source desktop client for Zetacoin (ZET), a chain that has produced blocks since 2013 on hybrid Scrypt proof-of-work and proof-of-stake with 30-second blocks. The client holds your keys in `wallet.dat`, stakes mature coins, mines with Scrypt hardware and runs a full node, and it ships for Windows, macOS and Linux. Every guide on this page is written against this release and lives in the repositories listed below.
